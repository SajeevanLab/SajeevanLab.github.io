# Deployment checklist

The repository is already configured for GitHub Pages from the `main` branch.

After uploading these files to `SajeevanLab/SajeevanLab.github.io`:

1. Keep the repository's Pages source as **Deploy from a branch → main → / (root)**.
2. Commit all files to `main`.
3. Wait for the Pages build to finish.
4. Open `https://sajeevanlab.github.io/`.
5. Check:
   - navigation links
   - publications filters
   - mobile menu
   - external DOI/ORCID/SRIBS links
   - page URLs
6. Replace/add lab photographs in `assets/images/` when available.
7. Update `_data/publications.yml` from the definitive publication list before treating the publications page as exhaustive.
